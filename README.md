تطبيق سطح مكتب **لويندوز وماك** (Electron + TypeScript + React) يجمع أدوات الصيانة في مكان واحد،
بواجهة عربية بخط IBM Plex Sans Arabic وأيقونات SVG موحّدة وسمة فاتحة/داكنة وستة ألوان تمييز.

### الرئيسية

- **درجة صحة الجهاز** من 100 في حلقة متحرّكة — تُحسب من الملفات القابلة للتنظيف
  ومساحة القرص والذاكرة وعدد برامج بدء التشغيل وتاريخ آخر تنظيف، مع بطاقة لكل
  عامل تنقلك للأداة التي تعالجه.
- **تنظيف ذكي بضغطة واحدة** — ينظّف الفئات الآمنة فقط ولا يلمس فئات "انتبه"،
  ويُرسل إشعار نظام عند الاكتمال.
- **لوحة أوامر** بـ `Ctrl+K` / `⌘K` — اكتب اسم أي صفحة أو إجراء وانتقل إليه.

### الأدوات الأساسية


- **🧹 منظّف القرص** — فحص وحذف الملفات المؤقتة، ذاكرة تخزين المتصفحات، ملفات
  تحديثات ويندوز، سلة المحذوفات، وغيرها — مع معاينة الحجم قبل الحذف.
- **🗑️ إزالة البرامج** — قائمة بكل البرامج المثبَّتة (من السجل مباشرة) مع الحجم
  والناشر، وإمكانية تشغيل أداة الإزالة الرسمية، ثم البحث عن المجلدات المتبقّية
  بعد الإزالة وحذفها.
- **📁 مدير ملفات** — تصفّح الأقراص والمجلدات، إعادة تسمية دفعية بنمط قابل
  للتخصيص، نقل، إنشاء مجلدات، وحذف آمن عبر سلة المحذوفات دائمًا.
- **🎵 محرر وسوم الأغاني** (على غرار Mp3tag) — عرض/تعديل العنوان والفنان
  والألبوم والسنة والنوع وصورة الغلاف لملفات MP3، تعبئة الوسوم من اسم الملف،
  وإعادة تسمية الملفات من الوسوم، بشكل دفعي.

### أدوات القرص

- **📊 محلّل المساحة** — يعرض حجم كل عنصر داخل المجلد بنِسب مرئية، مع التنقّل
  داخل المجلدات لمعرفة أين تذهب المساحة بالضبط.
- **🧬 الملفات المكرّرة** — بحث بالتجزئة (hash) عن نسخ مكرّرة داخل أي مجلد.
- **📦 أكبر الملفات** — ترتيب أكبر الملفات في مجلد حسب الحجم.
- **🗂️ مجلدات واختصارات** — المجلدات الفارغة تمامًا، والاختصارات التي اختفى هدفها.
- **🚀 بدء التشغيل** — تفعيل/تعطيل/حذف البرامج التي تعمل تلقائيًا مع ويندوز.

### الخصوصية والأمان

- **🕶️ خصوصية المتصفح** — مسح سجل التصفح والكوكيز والجلسات وبيانات النماذج من
  Chrome و Edge و Brave و Vivaldi و Opera و Firefox و Safari، لكل ملف تعريف على حدة.
  المفضّلة وكلمات المرور لا تُمسّ أبدًا.
- **✂️ الممزّق الآمن** — كتابة فوق الملف ببيانات عشوائية ثم أصفار (1 أو 3 أو 7 مرات)
  قبل حذفه، فيصعب استرجاعه ببرامج الاسترداد.
- **⬇️ التنزيلات القديمة** — ما نسيته في مجلد التنزيلات منذ أكثر من N يومًا، بأعمار
  وأحجام، ونقله إلى المهملات.

### أدوات النظام

- **⚡ العمليات** — كل ما يعمل الآن مع استهلاك المعالج والذاكرة، بحث وترتيب
  وتحديث تلقائي وإنهاء أي عملية.
- **⚙️ خدمات ويندوز** — عرض الخدمات وحالتها ونوع بدئها، وتشغيلها وإيقافها.
- **🌐 الشبكة** — المحوّلات وحركة البيانات، الاتصالات النشطة، اختبار اتصال،
  ومسح ذاكرة DNS.
- **💻 معلومات النظام** — حالة المعالج، الذاكرة، والأقراص لحظيًا.
- **📄 تقرير النظام** — لقطة Markdown كاملة عن الجهاز (النظام، الأقراص، ما يمكن
  تنظيفه، بدء التشغيل، البرامج المثبَّتة) للحفظ أو النسخ أو إرسالها للدعم الفني.
- **🧾 سجل التنظيف** — كل عملية تنظيف سابقة وكم مساحة حرّرت، مع إجمالي تراكمي.

### الإعدادات وشريط النظام

- السمة (حسب النظام / فاتح / داكن) ولون التمييز، أيقونة في شريط النظام مع
  "تنظيف ذكي الآن" من قائمتها، التشغيل عند تسجيل الدخول، الإشعارات، الفحص
  التلقائي، وإعدادات الأدوات. تُحفظ كلها في ملف `settings.json` داخل بيانات التطبيق.

كل الفحوصات الطويلة (المكرّرة، أكبر الملفات، تحليل المساحة، البحث) تعرض تقدّمها
لحظيًا مع عدد الملفات والمجلد الجاري فحصه، ويمكن إيقافها في أي لحظة.

## سياسة الأمان

- حذف ملفات مدير الملفات (بما فيها نتائج أداتي "المكرّرة" و"أكبر الملفات")
  **يمر دائمًا عبر سلة محذوفات ويندوز** — قابل للاسترجاع دائمًا.
- منظّف القرص يحذف فئات "junk" معروفة (ملفات مؤقتة/ذاكرة تخزين) بشكل نهائي بعد
  تأكيد صريح من المستخدم يعرض الحجم الإجمالي، لأن هذه الملفات تُعاد تلقائيًا من
  البرامج عند الحاجة. الفئات الأكثر حساسية (مثل Prefetch وملفات Minidump)
  مُعلَّمة بشارة "انتبه" ⚠️.
- مخلّفات إزالة البرامج تُعرض للمراجعة اليدوية قبل الحذف، وتُحذف فقط من مسارات
  معروفة وآمنة (Program Files، AppData، ProgramData).
- إعادة التسمية الدفعية لا تستبدل ملفًا موجودًا أبدًا، ولا تتوقف عند أول خطأ بل
  تُكمل وتُبلّغ بعدد ما تعذّر.
- يمكن إنشاء **نقطة استعادة نظام** قبل التنظيف من نافذة التأكيد نفسها.

## صلاحيات المدير

بعض فئات التنظيف تقع داخل مجلدات ويندوز المحمية (ملفات ويندوز المؤقتة،
Prefetch، تحديثات ويندوز، Delivery Optimization، Minidump) ولا يمكن حذفها دون
صلاحيات مدير. يكتشف التطبيق ذلك تلقائيًا ويعرض تنبيهًا مع زر **"إعادة تشغيل
التطبيق كمسؤول"** (عبر UAC)، بدل أن يحذف "صفر بايت" بصمت. باقي الفئات (الملفات
المؤقتة للمستخدم، ذاكرة المتصفحات، سلة المحذوفات) تعمل بصلاحيات المستخدم العادي.

## التشغيل محليًا (Windows فقط للتشغيل الفعلي)

```bash

npm install
npm run dev
```

يفتح التطبيق في نافذة Electron. معظم الميزات (السجل، سلة المحذوفات، مجلدات
ويندوز) تعمل فقط عند التشغيل على ويندوز فعليًا؛ التشغيل على أنظمة أخرى مفيد
لمعاينة الواجهة فقط.

## بناء ملف exe

### الطريقة 1 — بناء تلقائي عبر GitHub Actions (موصى بها)

عند أي دفع (push) إلى الفرع الرئيسي يتضمّن تغييرًا داخل هذا المستودع،
يعمل ملف `.github/workflows/build.yml` تلقائيًا على عامل
`windows-latest` وينتج:

- `CleanShelf-Setup.exe` — مثبّت NSIS عادي.
- `CleanShelf-Portable.exe` — نسخة محمولة بدون تثبيت.

يمكن تنزيلهما من تبويب **Actions** في المستودع، من قسم "Artifacts" لتشغيلة
البناء. يمكن أيضًا تشغيل البناء يدويًا من نفس التبويب عبر "Run workflow".

### الطريقة 2 — بناء يدوي على جهاز ويندوز

```powershell

npm install
npm run build:win
```

الملفات الناتجة تكون في `dist/`.

## ملاحظات ومحدوديات معروفة

- **الكتابة على وسوم الأغاني مدعومة حاليًا لملفات MP3 فقط** (عبر ID3v2)؛ القراءة
  والعرض تعمل لصيغ أخرى (FLAC، M4A، OGG، WAV) لكن الحفظ معطَّل لها في هذا
  الإصدار.
- تم تطوير التطبيق داخل بيئة Linux لا تملك وصولًا لتنزيل ثنائي Electron لويندوز،
  لذلك تحقّق البناء (type-check + حزم الكود + إنتاج ملفي exe) عبر GitHub Actions
  على ويندوز، لكن **لم تُجرَّب الواجهة تشغيليًا بالنقر على جهاز ويندوز بعد** —
  يُنصح بتجربة كل ميزة يدويًا بعد أول تثبيت.
- استعلامات السجل (Registry) وقوائم البرامج تعتمد على PowerShell المدمج في
  ويندوز؛ لا حاجة لتثبيت أي أداة إضافية.

## أدوات ماك الخاصة

- **🍎 مخلّفات التطبيقات المحذوفة** — سحب تطبيق إلى المهملات على ماك لا يحذف ما
  تركه في `Library`. تعثر الأداة على ملفات دعم تطبيقات لم تعد مثبَّتة.
- **🌐 ملفات اللغات غير المستخدمة** — تحمل التطبيقات عشرات اللغات؛ نُبقي الإنجليزية
  والعربية ونعرض الباقي للحذف.
- **🧠 تحرير الذاكرة** — أمر `purge` لتحرير الذاكرة غير النشطة.
- فئات تنظيف خاصة بماك: DerivedData و أرشيفات Xcode ودعم أجهزة iOS، ذواكر Homebrew
  و npm و Yarn و pip و Gradle و CocoaPods، ذاكرة Safari، النسخ الاحتياطية للآيفون،
  تقارير الأعطال، والمعاينة السريعة.

## المظهر والأيقونة

- زر في الشريط العلوي يبدّل بين **حسب النظام / فاتح / داكن** (اختصار `Ctrl+Shift+L`)،
  ولون التمييز يُختار من الإعدادات؛ يُحفظ كلاهما في إعدادات التطبيق.
- الخط IBM Plex Sans Arabic مضمّن في التطبيق (لا يحتاج اتصالًا)، والأيقونات SVG
  مرسومة بخط واحد في `src/renderer/components/Icon.tsx`.
- أيقونات شريط النظام في `build/tray/` (ملوّنة لويندوز، وقالب أحادي لماك).
- أيقونة التطبيق في `build/`: مصدرها ملفا SVG (`icon.svg` للأحجام الكبيرة،
  و`icon-small.svg` نسخة مبسّطة تبقى مقروءة عند 16px)، ومنهما يُولَّد `icon.ico`
  متعدد الأحجام (16 → 256). لإعادة توليدها بعد أي تعديل على الـ SVG:

```bash
cd build
npm install --no-save sharp png-to-ico
node generate-icons.mjs
```

## البنية التقنية

```
src/
  main/       عملية Electron الرئيسية: منطق النظام (سجل، ملفات، PowerShell)
    lib/      وحدات منطقية خالصة (قابلة لإعادة الاستخدام والاختبار)
    ipc/      معالجات IPC التي تربط الواجهة بمنطق main
  preload/    جسر contextBridge الآمن بين main والواجهة
  renderer/   واجهة React (TypeScript)، صفحة لكل أداة
  shared/     أنواع TypeScript مشتركة بين main والواجهة
```
